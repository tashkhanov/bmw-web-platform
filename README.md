# BMW Web Platform 🚗

Современный автомобильный веб-портал, посвященный бренду BMW. Платформа позволяет пользователям просматривать каталог автомобилей, детально изучать характеристики, скачивать обои высокого качества и оформлять заказы.

## Функционал
- **Каталог:** Динамический вывод автомобилей с фильтрацией и поиском через AJAX/API. Детальные страницы с характеристиками и галереей.
- **Система заказов:** Оформление заказов на автомобили для авторизованных пользователей (закрыто middleware).
- **Медиа-раздел:** Просмотр и скачивание обоев BMW (скачивание доступно только после авторизации).
- **Аутентификация:** Классическая регистрация и возможность входа через социальные сети (Google, GitHub) с помощью Socialite. Редактирование профиля.
- **Панель управления:** Мощная админка на базе Filament для управления авто, пользователями, заказами и контентом. Реализована кастомная загрузка изображений.

## Стек технологий
Проект построен на современном TALL-стеке:
- **Backend:** PHP 8.1+, Laravel 10
- **Admin Panel:** Filament PHP v3.3
- **Auth:** Laravel Breeze / Sanctum, Laravel Socialite
- **Frontend:** Tailwind CSS, Alpine.js, Vite, Axios

Проект имеет чистую MVC-архитектуру, использует встроенные паттерны Laravel и демонстрирует стандарты разработки производительных приложений на PHP.
